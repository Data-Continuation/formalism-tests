# Repo README Update Bundle

## Assumptions

1. The primary repo `README.md` needs a current full replacement.
2. `README-Plus.md` remains a protected supplemental owner file.
3. Bundle README files should live under `docs/bundles/`.
4. This bundle intentionally updates root `README.md`.

## Done

This bundle is done when the repo contains:

```text
README.md
docs/bundles/repo-readme-update-README.md
reports/repo_readme_update_report.json
receipts/repo_readme_update_receipts.jsonl
```

## What Changed

This updates the repository README to reflect:

```text
Stages 1–31 passed
StegVerse-001 active governed work-entity status
proof authority boundaries
Site mirror boundary
declared-task structure
docs placement policy
README / README-Plus policy
post-Stage-31 workstream
```

## Boundary

This bundle updates documentation only.

It does not run discovery, install core-lite, grant production authority, or modify proof receipts.
